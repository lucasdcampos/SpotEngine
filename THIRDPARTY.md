# Third-Party Libraries

The following third-party libraries and packages are used in the Spot Engine project.

## Core & Engine Dependencies
- **[BepuPhysics](https://github.com/bepu/bepuphysics2)** (`2.4.0`) - 3D Physics engine. **License:** Apache-2.0
- **[Serilog](https://serilog.net/)** (`4.4.0`) - Diagnostic logging. **License:** Apache-2.0
- **[Serilog.Sinks.Console](https://github.com/serilog/serilog-sinks-console)** (`6.1.1`) - Console sink for Serilog. **License:** Apache-2.0
- **[Silk.NET.Assimp](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - Bindings for Assimp. **License:** MIT
- **[Silk.NET.Input](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - Cross-platform input handling. **License:** MIT
- **[Silk.NET.OpenAL](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - Bindings for OpenAL. **License:** MIT
- **[Silk.NET.OpenAL.Soft.Native](https://github.com/dotnet/Silk.NET)** (`1.23.1`) - Native binaries for OpenAL Soft. **License:** MIT
- **[Silk.NET.OpenGL](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - Bindings for OpenGL. **License:** MIT
- **[Silk.NET.OpenGL.Extensions.ImGui](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - ImGui integration for Silk.NET. **License:** MIT
- **[Silk.NET.Windowing](https://github.com/dotnet/Silk.NET)** (`2.23.0`) - Cross-platform windowing. **License:** MIT
- **[StbImageSharp](https://github.com/StbSharp/StbImageSharp)** (`2.30.15`) - C# port of stb_image.h. **License:** Public Domain / Zlib
- **[StbVorbisSharp](https://github.com/StbSharp/StbVorbisSharp)** (`1.22.4`) - C# port of stb_vorbis.c. **License:** Public Domain / Zlib

- **[xunit.runner.visualstudio](https://github.com/xunit/visualstudio.xunit)** (`3.1.4`) - Visual Studio and dotnet test runner for xUnit. **License:** Apache-2.0
